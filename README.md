# Custom-merge-sort
A C++ implementation of merge sort with complexity analysis, correctness checks, testing, and edge-case evaluation.
## 项目简介

本项目实现了自定义归并排序算法，并分析该算法在不同输入条件下的运行表现。项目重点包括：理解问题要求、设计可靠的解决方案、验证程序正确性，以及分析算法效率。

## 实现与分析

- 将算法要求拆解为清晰的实现步骤；
- 分析算法的时间复杂度和内存使用；
- 针对不同输入规模和边界情况进行测试； 
- 使用正确性检查，将程序输出与预期排序结果进行比较；
- 考虑实现简洁性、运行性能和额外内存开销之间的取舍；
- 记录解决方案背后的思路，使项目能够被复查和复现。
  

## 对技术岗与产品岗的相关性

虽然本项目主要围绕排序算法展开，但它更重要的价值在于体现了解决技术问题的完整过程。我需要将一个技术任务拆解为具体步骤，明确程序的预期行为，考虑异常输入和边界情况，测试实现结果，并解释不同方案之间的取舍。


- 理解一个功能或工具应该如何运行；

- 识别异常输入和失败场景；
- 判断一个实现是否符合需求；
- 在用户需求、系统可靠性和技术限制之间进行权衡。
